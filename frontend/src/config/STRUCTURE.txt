HOW TO MODIFY ENDPOINTS
═══════════════════════════════════════════════════════════════════

1. Open: /frontend/src/config/api.js
2. Find: API_CONFIG.SERVICES
3. Edit: The URL you want to change
4. Save: All components automatically use the new URL


═══════════════════════════════════════════════════════════════════
EXAMPLE: Change Posts Endpoint
═══════════════════════════════════════════════════════════════════

Before:
  POSTS: 'https://sports321.vercel.app/api/posts'

After:
  POSTS: 'https://new-domain.vercel.app/api/posts'

Result:
  ✅ All components using apiHelper.getPosts() now use new URL
  ✅ No other file changes needed
  ✅ Consistent across entire application
